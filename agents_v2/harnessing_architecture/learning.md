## Routing Agent
    A routing agent (or router) acts as a gatekeeper or traffic controller. Its sole responsibility is to analyze an incoming prompt or state and decide which single downstream agent or tool should handle it next.

## Superviser Agent
    A supervisor agent acts as a manager or project lead. Instead of just handing off a task once, it oversees a team of worker agents dynamically across an entire multi-step workflow.

    It stays active throughout the task. It can delegate sub-tasks to multiple agents sequentially or in parallel, review intermediate outputs, correct errors, re-assign tasks, and decide when the overall objective has been achieved so the final answer can be returned to the user.
